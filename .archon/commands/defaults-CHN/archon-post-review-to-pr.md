# 将审查结果发布到 PR

---

## 任务目标

读取代码审查发现产物，并将格式化的摘要作为评论发布到 PR 上。

---

## 阶段 1: 加载 - 获取上下文

### 1.1 获取 PR 编号

```bash
PR_NUMBER=$(cat $ARTIFACTS_DIR/.pr-number)
```

**若未找到：**
```
错误: 在 $ARTIFACTS_DIR/.pr-number 中未找到 PR 编号
缺少 PR 编号无法发布审查。
```

### 1.2 读取审查发现

```bash
cat $ARTIFACTS_DIR/review/code-review-findings.md
```

**若未找到：**
```
错误: 在 $ARTIFACTS_DIR/review/code-review-findings.md 中未找到审查结果
请先运行代码审查。
```

**阶段 1 检查点:**
- [ ] PR 编号已加载
- [ ] 审查发现已加载

---

## 阶段 2: 格式化 - 构建 PR 评论

### 2.1 提取关键信息

从审查发现中提取：
- **结论**: 批准 / 请求修改 / 需要讨论
- **概要**: 2-3 句话概述
- **发现**: 所有发现项及其严重程度和位置
- **统计**: 按严重程度统计的发现数量

### 2.2 构建评论文本

将审查格式化为 GitHub 友好的评论：

```markdown
## 代码审查

**结论**: {批准 | 请求修改 | 需要讨论}

{发现中的概要}

---

### 发现

{每项发现：}

#### {严重程度图标} {标题}

**严重程度**: {严重|高|中|低} **类别**: {类别} **位置**: `{file}:{line}`

{问题描述}

<details>
<summary>建议修复</summary>

```typescript
{推荐修复代码}
```

**原因**: {理由}

</details>

---

{发现列表结束}

### 统计

| 严重程度 | 数量 |
|----------|------|
| 严重 | {n} |
| 高 | {n} |
| 中 | {n} |
| 低 | {n} |

{若存在正面评价：}

### 亮点

{审查中的正面评价}

---

*自动代码审查*
```

**严重程度图标：**
- 严重 -> 红色圆点
- 高 -> 橙色圆点
- 中 -> 黄色圆点
- 低 -> 蓝色圆点

**阶段 2 检查点:**
- [ ] 评论文本已格式化
- [ ] 所有发现已包含
- [ ] 统计表格已呈现

---

## 阶段 3: 发布 - 评论 PR

### 3.1 发布评论

```bash
gh pr comment {PR_NUMBER} --body "$(cat <<'EOF'
{格式化后的评论文本}
EOF
)"
```

### 3.2 验证

```bash
# 检查评论是否已发布
gh pr view {PR_NUMBER} --comments --json comments --jq '.comments | length'
```

**阶段 3 检查点:**
- [ ] 评论已发布到 PR
- [ ] 已验证评论存在

---

## 阶段 4: 输出 - 向用户报告

```markdown
## 审查已发布到 PR

**PR**: #{PR_NUMBER}
**结论**: {结论}
**发现**: {总数} ({严重} 项严重, {高} 项高, {中} 项中, {低} 项低)

审查评论已发布到 Pull Request。
```

---

## 错误处理

### PR 未找到
- 验证 PR 编号是否正确
- 检查 PR 是否仍然开放
- 向用户报告错误

### 评论发布失败
- 检查 GitHub 认证状态
- 若内容过长，尝试缩短正文
- 报告详细错误信息

### 无发现
- 发布一条干净的审查评论："未发现问题，LGTM！"

---

## 成功标准

- **FINDINGS_LOADED**: 审查产物已成功读取
- **COMMENT_FORMATTED**: PR 评论已构建并包含所有发现
- **COMMENT_POSTED**: 评论已在 PR 上可见
