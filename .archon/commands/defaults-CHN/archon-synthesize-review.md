# 综合审查报告

---

## 任务目标

阅读所有并行审查代理的产物，将发现综合为统一报告，创建主产物，并向 GitHub PR 发布全面的审查评论。

**输出产物**：`$ARTIFACTS_DIR/review/consolidated-review.md`
**GitHub 操作**：发布包含完整审查的 PR 评论

---

## 阶段一：加载 -- 收集所有发现

### 1.1 从注册文件获取 PR 编号

```bash
PR_NUMBER=$(cat $ARTIFACTS_DIR/.pr-number)
```

### 1.2 读取范围

```bash
cat $ARTIFACTS_DIR/review/scope.md
```

### 1.3 读取所有代理产物

```bash
# 读取每个代理的发现
cat $ARTIFACTS_DIR/review/code-review-findings.md
cat $ARTIFACTS_DIR/review/error-handling-findings.md
cat $ARTIFACTS_DIR/review/test-coverage-findings.md
cat $ARTIFACTS_DIR/review/comment-quality-findings.md
cat $ARTIFACTS_DIR/review/docs-impact-findings.md
```

**阶段一检查点：**
- [ ] 已识别 PR 编号
- [ ] 已读取全部 5 个代理产物
- [ ] 已提取各代理的发现

---

## 阶段二：综合 -- 合并发现

### 2.1 按严重程度汇总

合并所有代理的发现：
- **严重（CRITICAL）**：合并前必须修复
- **高（HIGH）**：建议合并前修复
- **中（MEDIUM）**：考虑修复（已提供选项）
- **低（LOW）**：锦上添花（延后处理或创建 issue）

### 2.2 去重

检查重叠的发现：
- 同一问题被多个代理报告
- 应归为一组的相关问题
- 冲突的建议（予以解决）

### 2.3 排定优先级

按以下因素排列发现：
1. 严重程度（严重 > 高 > 中 > 低）
2. 用户影响
3. 修复难度
4. 不修复的风险

### 2.4 编制统计

```
发现总数：{n}
- 严重（CRITICAL）：{n}
- 高（HIGH）：{n}
- 中（MEDIUM）：{n}
- 低（LOW）：{n}

按代理分布：
- 代码审查（code-review）：{n} 项发现
- 错误处理（error-handling）：{n} 项发现
- 测试覆盖（test-coverage）：{n} 项发现
- 注释质量（comment-quality）：{n} 项发现
- 文档影响（docs-impact）：{n} 项发现
```

**阶段二检查点：**
- [ ] 已按严重程度汇总发现
- [ ] 已移除重复项
- [ ] 已确定优先级顺序
- [ ] 已编制统计数据
