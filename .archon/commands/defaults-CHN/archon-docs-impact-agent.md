# 文档影响分析智能体

---

## 你的任务

分析 PR 变更是否需要更新项目文档：CLAUDE.md、docs/ 目录、智能体定义或其他文档。生成结构化的分析制品并提供建议。

**输出制品**: `$ARTIFACTS_DIR/review/docs-impact-findings.md`

---

## 阶段 1: 加载 -- 获取上下文

### 1.1 从注册表获取 PR 编号

```bash
PR_NUMBER=$(cat $ARTIFACTS_DIR/.pr-number)
```

### 1.2 读取范围

```bash
cat $ARTIFACTS_DIR/review/scope.md
```

**关键**: 检查"不在范围内 (范围限制)"章节。其中列出的项目是**故意排除的** -- 不要将其标记为缺失的文档需求！

### 1.3 获取 PR 差异

```bash
gh pr diff {number}
```

### 1.4 读取当前文档

```bash
# 读取 CLAUDE.md
cat CLAUDE.md

# 列出 docs 目录
ls -la $DOCS_DIR

# 列出智能体定义
ls -la .claude/agents/ 2>/dev/null || true
ls -la .archon/commands/ 2>/dev/null || true
```

**阶段 1 检查点:**
- [ ] PR 编号已识别
- [ ] 变更已理解
- [ ] 当前文档已阅读

---

## 阶段 2: 分析 -- 检查文档影响

### 2.1 CLAUDE.md 影响

检查变更是否影响以下文档内容：
- 命令或斜杠命令
- 工作流
- 开发环境设置
- 环境变量
- 数据库架构
- API 端点
- 测试说明
- 代码模式/规范

### 2.2 docs/ 目录影响

检查变更是否影响：
- 架构文档
- 入门指南
- 配置文档
- API 文档
- 部署说明

### 2.3 智能体/命令定义

检查变更是否影响：
- 智能体能力
- 命令参数
- 工作流步骤
- 工具使用模式

### 2.4 README 影响

检查变更是否影响：
- 功能列表
- 安装说明
- 使用示例
- 配置选项

**阶段 2 检查点:**
- [ ] CLAUDE.md 影响已评估
- [ ] docs/ 影响已评估
- [ ] 智能体定义已检查
- [ ] README 已检查
